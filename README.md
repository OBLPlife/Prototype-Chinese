# 虐杀原形（2009）简体中文汉化补丁

适用于 PC 版《虐杀原形》（Prototype 2009）的简体中文补丁，提供菜单、任务、技能、剧情及游戏内对白字幕汉化。

**当前版本：** v0.2.13（本地资源差分版） · [Releases 下载页面](https://github.com/OBLPlife/Prototype-Chinese/releases)

安装器从玩家本地游戏读取资源，生成并注册中文覆盖文件。

## 安装与还原

**安装汉化**

1. 退出游戏，建议使用游戏的英语语言资源。
2. 从 [Releases](https://github.com/OBLPlife/Prototype-Chinese/releases) 下载 `Prototype_ZH_CN_Setup.exe`。
3. 将安装器放入游戏根目录，与 `cementfiles.p3d` 位于同一文件夹。
4. 双击安装器，点击「安装」。安装器内置运行环境，玩家无需单独安装 Python。
5. 安装完成后正常启动游戏。

**恢复原版**

退出游戏，在同一目录重新运行安装器，点击「还原」。

安装器会备份被修改的相关文件，并在还原时恢复安装前的内容；请保留游戏目录下的 `PrototypeZh` 备份文件夹。若其他补丁之后接管了同名文件，还原时会保留其修改。

首次安装需要在游戏所在磁盘预留约 **1.2 GiB** 可用空间以生成中文资源；如需备份现有同名文件，还需要额外空间。

## 汉化内容

- **18,402 条主要文本记录**：包含 3,127 条界面文本、957 条剧情字幕和 14,318 条音频内嵌对白字幕。
- **菜单与任务**：覆盖设置、操作提示、任务目标、技能名称、升级说明和「阴谋之网」等内容。
- **对白与字幕**：处理剧情、战斗与角色对白，补充原版音频资源中独立存放的字幕。
- **中文字体**：支持完整 GBK 字符集，标题、菜单正文和字幕采用不同字重的思源黑体（Noto Sans CJK）。
- **显示优化**：调整升级菜单文字区域、技能价格及部分字幕布局，改善中文排版。
- **术语统一**：统一游戏内组织、能力和项目名称；制作人员姓名及现实公司名称保留原文。
- **保留原版画面**：街头招牌、广告、海报等场景贴图不作翻译。

汉化补丁可以独立安装，也包含现代兼容补丁相关显示模式选项的中文文本。

## 资源差分与兼容性

安装包保存译文、必要的字体及界面差分和汉化运行组件。安装时依据玩家本地资源生成中文覆盖文件。

安装器检查汉化涉及的资源和接口，不以整个游戏文件的哈希作为唯一限制。如果相关资源与制作时不同，会弹出确认提示；对无法匹配的部分保留原文件，因此部分内容可能无法汉化。

## 从源码构建

仓库包含译文目录、C++ 汉化运行组件、ActionScript 界面源码、C# 安装器及 Python 资源构建工具。构建需要英文版游戏资源及外部工具、字体文件。

主要依赖包括 Windows x64、Python 3.13、fontTools、JDK、FFDec 26.4.0、MSVC x86、Windows SDK、.NET Framework 4.x C# 编译器、Noto 字体和官方 Python 3.13.12 嵌入式运行包。字体来源及校验值见 [catalog/font-sources.json](catalog/font-sources.json)。

构建脚本按工作区布局读取 `source/PrototypeZh/`、`vendor/` 和 `work/` 等目录。完整步骤见 [源码构建说明](packaging/SOURCE.md)，差分安装方式见 [安装包说明](packaging/README.md)。
