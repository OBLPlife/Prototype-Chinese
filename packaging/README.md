# 《虐杀原形》简体中文补丁 0.2.13 差分版

## 安装与还原

退出游戏，把 Prototype_ZH_CN_Setup.exe 放到游戏根目录（与 cementfiles.p3d 同级），双击后选择“安装”。安装器自带运行环境，可以离线使用。还原时从同一目录再次运行，选择“还原”。

本版沿用 0.2.13-font-weights 的译文、GBK 字库和汉化运行库。安装时从本机读取任务、界面、字幕、制作人员表等资源，使用本机语音及其他原有数据生成汉化覆盖包。覆盖包约 1 GiB，首次安装建议游戏所在磁盘至少有 1.2 GiB 可用空间。若要替换已有的同名文件，还需为备份和临时文件预留空间。请保留游戏目录内的 PrototypeZh 备份目录供还原使用。

安装器检查汉化涉及的资源和运行库所用的引擎接口。各来源的游戏均可安装，不校验整部游戏或主程序的哈希。所需资源产生变化时，仅询问“所需资源存在变化，可能无法达到预期效果，是否继续安装？”。选择“否”取消。选择“是”后，安装器按可识别的本地资源合并。对无法匹配的项目保留本机资源，并在完成时显示未完整汉化的项目数。明细在 PrototypeZh/state.json 的 delta_result 段。用户自行决定是否继续并承担变更资源下的效果。

汉化可以单独安装。与现代兼容补丁、高清补丁组合使用时，若后安装的补丁也改动了同一项字幕或界面，重新运行汉化安装器可根据当前资源再次合并。还原会保留其他补丁新增的资源注册，以及之后由其他补丁接管的文件。

## GitHub 源码

`Prototype-Chinese-v0.2.13-delta-source.zip` 和已展开的 `Prototype-Chinese/` 目录均只包含项目源码、翻译表及许可说明。需要安装汉化时使用单独提供的 `Prototype_ZH_CN_Setup.exe`。维护译文、准备本机游戏资源和构建依赖的步骤在源码仓库根目录的 `README.md`。
